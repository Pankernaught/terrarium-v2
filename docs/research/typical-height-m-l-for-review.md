# typicalHeightCm — M/L entries for manual review

60 plants where no direct species-specific height was found. Values are **not yet in
`plants.json`** — enter them via the Plant Admin app after reviewing.

## How to use this

- **Suggested** = my best estimate (genus inference, scaled houseplant figure, or `maxHeightCm × 0.7`).
- **Conf** = M (reasonable inference) or L (sparse/guess — treat as placeholder only).
- **Source** = the closest relevant page found, even if it doesn't cite height directly. "—" = nothing found.
- Renderer already falls back to `maxHeightCm × 0.7` for null values, so leaving a row null is fine if the suggestion looks wrong.
- `equisetum-bogotense` is flagged **recommend null** — genus range is 20 cm–1.5 m with no cultivar data.
